# 异环 · 店长特供区域连点脚本

适用于 Windows PC 桌面版，也可用于主屏幕上的安卓模拟器窗口。以普通鼠标点击、分数 OCR 和体力不足截图匹配实现：锤子区域连点 → 右上角分数达到 1900 → Esc → 退出 → 确认领取 → 重新进入 → 循环，识别都市体力不足时停止。尚未在真实游戏中验证，需要先录入你自己的界面。不能直接在安卓手机运行。

## 安装

安装 Python 3.11 或 3.12。在本目录打开 PowerShell：

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe automation.py configure
```

如果只有 Python 3.11，将第一行改为 `py -3.11 -m venv .venv`。

## 录入界面

1. 将游戏置于主屏幕，建议使用窗口模式，固定分辨率、窗口位置和 UI 缩放。配置窗口和游戏之间可用 Alt+Tab 切换。
2. 在配置工具中框选实际需要快速点击的区域，避开退出、购买等按钮。
3. 框选右上角完整的 `当前分数/1900`，包括斜杠及左右两侧数字，留少量边距。运行时 OCR 读取左侧当前分数，连续确认达到 1900 才退出，不会把右侧的 1900 当作完成。截图按钮会隐藏配置窗口，然后让你拖动选区。
4. 游戏显示「都市体力不足」或同等含义提示时，录入对应文字/图标。必须使用真正表示不足的提示，不能使用正常体力数字。如果你尚无这张图，需要等提示出现后补录，配置工具会保留已有配置。
5. 点击“在退出步骤开头加入 Esc”一次，再按实际流程录入“退出”“确认领取”点击步骤；随后录入重新进入步骤，例如选择关卡、开始按钮。点击“添加步骤”后，在 3 秒内将鼠标移到游戏中的对应按钮，工具记录指针位置，不会替你点击。自行完成页面切换，再记录下一个按钮。每步等待默认为 2 秒，加载慢时增加。
6. 完成后保存，生成本地 `config.json` 和 `captures/`。关闭配置工具。

分数区域和不足提示需要分别在对应画面录入。已有配置可以多次打开工具补录并保存。首次保存要求两张截图、点击区域和两组操作步骤齐全。

## 检查与运行

先在右上角显示分数的界面执行：

```powershell
.\.venv\Scripts\python.exe automation.py check
```

输出中“`OCR 当前分数`”应与左侧游戏分数一致；达到 1900 时 `goal: True`，低于 1900 时应为 `False`，读不到时当前分数为 `None`。对体力不足画面同样检查 `stamina: True`，并在正常画面验证为 `False`。此命令只截图，不点击。若不匹配，先重新截取稳定文字，并核对窗口位置。

进入店长特供**新一轮可点击阶段**，运行：

```powershell
.\.venv\Scripts\python.exe automation.py run
```

有 5 秒准备时间，将游戏置于前台。运行期间保持游戏前台，不移动游戏窗口，不操作其他程序。首次建议在 `config.json` 中将 `max_rounds` 改为 `2`，观察一整个退出、重进流程，再提高上限。

**停止：按 F8、将鼠标移到主屏幕角落，或在终端按 Ctrl+C。** Esc 用于脚本打开退出菜单，因此紧急停止使用 F8。 检测到体力不足不会继续点击确认或进入下一轮。仅有未知错误弹窗而没有配置的不足提示时，会按超时保护停止，不能据此判定体力已清完。

## 可调参数

关闭脚本后可编辑 `config.json`：

| 参数 | 默认值 | 含义 |
| --- | --- | --- |
| `click_interval` | `0.08` | 连点间隔，约每秒 12 次；系统开销可能降低实际速度 |
| `scan_interval` | `0.25` | 识别检查间隔，单位秒 |
| `confirm_frames` | `3` | 连续确认次数，至少 2 |
| `target_score` | `1900` | 达成目标分数，当前分数大于等于它时退出；同时作为识别分母 |
| `stamina.threshold` | `0.88` | 体力不足图片相似度阈值；优先改善截图，降低阈值可能误判 |
| `round_timeout` | `180` | 单轮最长秒数，超时停止 |
| `transition_timeout` | `30` | 重进后等待旧目标提示消失的最长秒数 |
| `max_rounds` | `100` | 总轮数上限，完成末轮后退出，不再进入 |
| `max_minutes` | `60` | 总运行时间上限 |
| `exit_steps` / `enter_steps` 中的 `delay` | `2.0` | 每次点击后的等待秒数 |

识别到分数达标时先暂停连点，连续确认后才退出；重新进入后确认分数已低于目标，避免旧分数触发重复退出。启动时读不到分数会直接停止；连点阶段读不到时暂停点击，等重新读到分数后继续，超时则停止。识别体力不足需要连续确认。体力不足停止是基于你录入的提示，并不读取游戏中的体力数值。

## 验证范围与限制

循环控制、体力不足停止、超时、残留成功提示、紧急停止和轮数上限有自动化测试：

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

这些测试使用模拟屏幕，不能代替真实游戏验证。分数使用 RapidOCR（依赖包自带模型，无需 API 密钥或单独安装 Tesseract），体力不足使用截图匹配。分辨率、缩放或提示样式改变后应重新配置。退出/重进步骤使用固定坐标和等待时间，错误页面、窗口失去前台或加载时间变化可能导致点击错误位置；首次运行请观察并随时停止。部分游戏可能不接收模拟鼠标输入，需要在实际设备确认，当前实现不提供绕过方式。
