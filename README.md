# 异环助手 · 店长特供 1.1.10

Windows 10/11 x64 桌面应用，安装后通过桌面“异环助手”打开中文 GUI。使用 EXE 安装包时无需单独安装 Python；也支持下载源码并通过 PowerShell 运行。新版内置玩家提供的七图界面模板和操作位置。

**1.1.10 更新：**移除 GUI 下方的识别参考图片、“七图流程说明”入口及侧栏静态流程介绍，让运行记录获得更多空间。模板和识别流程保留在内部代码中。保留 1.1.9 的滚轮与数字 OCR 提速、独立“滚动间隔”和画面光标反馈。

## 安装与开始

### 方法一：EXE 安装包

[直接下载 Windows EXE 安装包](https://github.com/Tracy1-pixel/NTE-AI/releases/download/v1.1.10/NTE-AI-Setup-1.1.10.exe)，或打开 [Releases 下载页面](https://github.com/Tracy1-pixel/NTE-AI/releases/latest)，在 Assets 中选择 `NTE-AI-Setup-1.1.10.exe`。双击安装后，通过桌面 **“异环助手”快捷方式** 打开中文界面，点击“开始运行”或“停止”。无需下载源代码、解压 ZIP 或安装 Python。已有旧版可直接安装升级，应用配置目录为 `%LOCALAPPDATA%\NTE-AI`。

### 方法二：EXE 下载不了或无法使用时，下载源码并用 PowerShell 运行

1. 从 [Python 官网](https://www.python.org/downloads/windows/) 安装 **Python 3.12（64 位）**，安装时保留 Python Launcher（`py` 启动器）选项。
2. [下载源码 ZIP](https://github.com/Tracy1-pixel/NTE-AI/archive/refs/heads/main.zip)，或在仓库点击 **Code → Download ZIP**。将 ZIP 完整解压，进入能看到 `app.py`、`requirements.txt` 和 `assets` 的文件夹。如果已经下载了这样的源码文件夹，可以直接使用。
3. 在该文件夹空白处右键选择 **“在终端中打开”**，确认使用 PowerShell。Windows 10 可按住 **Shift** 再右键，选择 **“在此处打开 PowerShell 窗口”**。
4. 先检查 Python 版本：

```powershell
py -3.12 --version
```

显示 `Python 3.12.x` 后，在同一窗口依次执行：

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe app.py
```

首次安装依赖需要联网；看到依赖安装完成后，再执行最后一行打开中文界面。此方式直接使用虚拟环境中的 Python，无需执行 `Activate.ps1`，也无需修改 PowerShell 执行策略。

如果提示找不到 `py` 或没有 Python 3.12，请回到第 1 步安装相应版本和 Launcher，重新打开 PowerShell 后再试。如果提示找不到 `requirements.txt` 或 `app.py`，请回到第 2 步中的源码文件夹再打开终端。

以后启动时，在同一源码文件夹打开 PowerShell，只需执行：

```powershell
.\.venv\Scripts\python.exe app.py
```

**可选：为源码版创建桌面快捷方式。** 首次成功运行并关闭助手后，在同一源码文件夹的 PowerShell 中执行下面整段代码：

```powershell
$nteSourceRoot = (Get-Location).Path
$nteShortcutShell = New-Object -ComObject WScript.Shell
$nteDesktopPath = [Environment]::GetFolderPath('Desktop')
$nteSourceShortcut = $nteShortcutShell.CreateShortcut((Join-Path $nteDesktopPath '异环助手（源码）.lnk'))
$nteSourceShortcut.TargetPath = Join-Path $nteSourceRoot '.venv\Scripts\pythonw.exe'
$nteSourceShortcut.Arguments = '"' + (Join-Path $nteSourceRoot 'app.py') + '"'
$nteSourceShortcut.WorkingDirectory = $nteSourceRoot
$nteSourceShortcut.Save()
```

之后双击桌面 **“异环助手（源码）”** 即可打开界面。这个快捷方式依赖当前源码目录，请保留该目录及其中的 `.venv` 文件夹。

### 游戏准备与开始运行

助手**沿用游戏当前的窗口尺寸和位置**，不会调整游戏窗口或修改游戏设置。读取实际内容区后，自动换算识别区域和点击坐标。助手使用独立的深色控制台界面，显示窗口尺寸、运行阶段、营业额和完成 / 失败次数。

游戏窗口须在主屏幕完整可见。窗口位置可以改变，识别截图与点击坐标始终跟随游戏内容区，不包括桌面、标题栏和边框。不再要求固定 1920×1080，也不会为了适配桌面移动或缩放游戏窗口。

1. 打开店长特供的**图一初始界面**。
2. 打开助手，点击“刷新”，在“绑定游戏窗口”下拉框选中《异环》。标题能唯一识别时会自动选中。游戏打开后再刷新；多个同名窗口须手动选择。
3. 在助手主页设置点击、识别和滚动间隔，点击“开始运行”，助手会自动最小化，5 秒内切回图一。助手会尝试将所选游戏窗口置于前台，读取当前内容区尺寸，再确认图一。随后先连续识别游戏光标，识别左侧横向连续三颗星的整体锚点，将光标移到锚点中心开始逐批滚动，每批 OCR 查找 `3-10`，找到就点击“钢琴家”；确认右侧已选中关卡后，将光标移到右下角点击“开始营业”，继续倒计时和锤子连点。窗口尺寸或位置变化时，会按当前内容区重新换算坐标。
4. “检查画面”只读，不会改变尺寸或点击，直接检查当前窗口。初始界面应显示 `home`，都市体力数值应与游戏一致。
5. **点击“停止”或按 F8 手动停止。** 助手运行时会最小化，可通过任务栏恢复界面点击停止；切到助手会暂停游戏操作。任务终止后，助手会自动恢复 GUI，显示结束原因和运行记录。运行中关闭 GUI 会提示先停止。鼠标移到角落、Esc、轮数和总时长不再是停止条件。

游戏切到后台、最小化或移出主屏幕时暂停操作；将窗口完整移回主屏幕并切回游戏后继续。F8 可停止当前运行。

GUI 只展示窗口绑定、运行参数、操作按钮、实时状态和运行记录。识别参考图片及七图流程说明仅用于内部实现，不显示在界面中。无需手动录入不足提示、Esc 或进出步骤。1.0 的轮数、总分钟数和旧坐标配置在新版流程中不生效。

### 滚轮与 OCR 速度

“滚动间隔”默认 **0.1 秒**，最小 **0.05 秒**。每批仍发送 3 格向下滚轮，然后等待列表更新，再识别 `3-10`；不增加每批跨度，避免跳过目标。删除滚动后重复的按钮切换等待和识别间隔等待。间隔表示画面更新等待时间，实际滚轮频率还受截图、光标核验和 OCR 耗时影响。列表动画未稳定或识别困难时可调到 `0.2`～`0.3` 秒。

营业额、都市体力和领取消耗使用固定单行区域直接识别，省去重复的文字检测和方向分类；低置信度或格式错误时回退完整 OCR。选关滚动期间不重复识别右侧标题；点击 `3-10` 后重新识别标题确认选中。左侧编号仍使用完整 OCR 获取点击位置。所有数值每次从新截图读取，仍需原有的连续确认，不缓存体力或消耗，不把读不到当作零。

云端 CPU 对玩家数字截图的预热测试：旧数字 OCR 约 **164～534 毫秒/次**，新直接识别约 **13～27 毫秒/次**。这仅是数字区域 OCR 耗时，不是整轮耗时或玩家电脑上的速度保证。也验证了原图与缩小后还原的数字样例。

## 游戏左下角状态栏

运行时，在游戏内容区左下角显示半透明状态栏，持续更新**实际窗口尺寸、当前阶段、营业额、完成轮数和连续失败次数**。内容区不可见或出现未知画面时显示暂停原因；恢复正确界面后继续。切换到其他窗口、最小化游戏或结束运行时隐藏状态栏。

状态栏采用普通 Windows 浮窗，鼠标点击穿透且不抢游戏焦点。截图识别时排除状态栏；旧版 Windows 或排除失败时，在截图期间临时隐藏，以免遮挡左侧选关的 OCR。状态栏随游戏窗口位置和尺寸变化，显示当前实际尺寸。

## 光标确认与三星整体锚点选关

点击开始后，助手自动最小化，确认图一，然后**先识别玩家照片中的游戏箭头光标，识别成功后才移动和滚动**。光标是图形，使用 OpenCV 轮廓识别；关卡文字 `3-10 钢！琴！家！` 使用 OCR。

默认识别依据照片中箭头的尖头、宽肩和内凹轮廓，支持不同大小。当前版本在游戏截图中定位箭头，不要求它靠近 Windows 系统坐标；还检查箭头方向和完整形状，避免把文字或家具边缘当成光标。多个画面候选无法唯一定位时暂停；定位后在上次确认位置周围跟踪。截图不包含系统光标时，读取并绘制当前 Windows 光标进行图形识别；游戏自己绘制的光标直接在画面中识别。不会只因为鼠标坐标存在就视为识别成功。

未识别到目标光标时，状态栏显示“识别游戏光标”，暂停移动、滚动和点击，等待光标出现；请先将鼠标置于游戏内容区。识别成功后，在左侧关卡栏寻找**横向连续三颗金色五角星**：尺寸相近、间距均匀的三颗星组合成一个整体锚点，光标移动到这个整体的中心，再开始向下滚动。每批滚动前重新定位三星组合，每批滚动后用 OCR 查找 `3-10`，找到即停止滚动并点击。编号已经出现在当前列表时，直接点击，无需额外滚动。确认选中后，再移动到右下角点击开始营业。

`3-10` 可作为独立 OCR 文字识别，无需同时读出“钢琴家”名称；`13-10`、`3-100` 等不同编号不会作为目标。三星组合只在左侧关卡栏识别。完整三星锚点未出现时暂停鼠标移动和滚动；连续两批列表不再变化且仍未读到 `3-10` 时，暂停滚轮但继续 OCR 等待，不会随意点击其他关卡。后续领取循环会再次确认光标和三星锚点，失败直接重试仍按原流程进行。

这张照片并非原始游戏截图，默认轮廓识别尚未在玩家设备验证；如果持续无法识别，应提供清晰的游戏原始截图以进一步适配。F8 或停止按钮仍可结束等待，并恢复 GUI。

## 鼠标输入与操作核验

当前版本区分两种光标：

- **画面中的游戏光标**：从截图获取真实位置，发送小批相对输入，再截图核验并修正；即使 Windows 系统坐标被游戏固定，也以画面反馈判断是否到达。不会将发送的目标坐标当作实际位置，不修改游戏的鼠标限制。光标丢失、候选有歧义或输入后画面光标不动时暂停，不继续点击。
- **Windows 光标**：从系统读取位置，保留相对 `SendInput`、绝对 `SendInput` 和 `SetCursorPos` 定位；输入后核验系统坐标及目标位置处的光标。目标不在系统活动范围时暂停。

选关、开始营业、锤子连点、退出和领取都使用对应的光标反馈。真实游戏是否接收这些输入仍需实测，测试通过不能代替玩家设备的结果。

新增 **“鼠标诊断”** 按钮：选中游戏窗口后点击，助手最小化，5 秒内切回游戏；只读输出系统坐标、`GetClipCursor` 鼠标活动范围、助手和所选游戏进程实际管理员状态、游戏内容区及前台状态。诊断不移动、点击或滚动。每次开始运行也会自动输出权限和范围信息。系统光标的目标不在活动范围时暂停；画面光标使用画面位置反馈。不会解除游戏的鼠标限制。

如果手动能移动、脚本不能移动，请复制“鼠标诊断”及“鼠标移动未确认”完整记录。`SendInput` 返回已接收，只代表 Windows 接收了事件，不能证明游戏处理了事件；日志和测试不会将二者混同。

OCR 读到 `3-10` 只证明找到了关卡文字。发送点击后，须识别右侧标题确认选中，才允许开始营业；开始点击后须识别倒计时 / 营业画面，才报告开始成功。滚轮输入后列表不变时，显示“列表未变化，无法确认是否到底或游戏未接收输入”，不会直接宣称已滚到底。

如果游戏使用管理员权限，助手也需右键选择“以管理员身份运行”；两者权限相同仍无法操作时，应查看上述坐标与游戏光标确认日志。Windows 自检实际向专用测试窗口发送移动、点击和滚轮，并核验接收事件；也检查绝对坐标定位、SetCursorPos、活动范围和进程权限读取。这能验证输入接口，不能保证《异环》接受模拟输入；真实游戏仍需玩家实测。

## 自动流程

| 图片 | 识别与操作 |
| --- | --- |
| 图一 | 连续确认店长特供标题与开始营业按钮，才允许开始；先连续识别游戏光标，识别左侧连续三星整体锚点，光标移到锚点上逐批滚动 |
| 图二 | 每批滚动后 OCR 查找 `3-10 钢！琴！家！`，找到即停止滚动，移动光标点击关卡并确认右侧已选中，再将光标移到右下角点击开始营业 |
| 图三 | 倒计时期间即可开始连续点击左侧锤子 |
| 图四 | 保持锤子连点，定期读取右上角营业额 |
| 图六 | 连续确认营业额达到 1900 后停止连点，点击左上角退出图标 |
| 图七 | 连续确认成功结算，读取领取下方消耗，非零且可读时领取；回到图一继续 |
| 图五 | 连续确认失败，点击“重新挑战”；直接等待倒计时并连点，不返回图一选关 |

每次成功领取并返回图一，连续失败计数归零。连续失败三次终止当前运行。

领取下方的消耗**不是固定 48**。每次结算都会重新 OCR 读取当前数字，任何可读的非零消耗都允许领取并继续循环；例如 `48 → 24 → 7 → 0`，前三次领取，最后确认 0 时停止，且不点击领取。内部识别素材中的 48 只是截图样例。

都市体力完整分数中的左侧值连续确认为 0，或者领取按钮下方的消耗连续确认为 0，都自动停止。OCR 读不到为未知，**不会当作 0**。这些是自动结束条件；手动停止使用停止按钮或 F8。

初始画面不匹配时显示“界面错误”并拒绝开始。运行过程中出现未知画面或页面切换迟迟未完成时，暂停点击并在日志显示错误，继续等待正确界面或 F8；不会因普通加载超时直接退出。挑战自身倒计时结束出现图五时走失败重试流程。

营业额达标依据左侧数字 ≥1900；星星是界面反馈，不代替营业额判断。工具使用截图、OCR 和普通鼠标输入，不读取游戏内存。

## 验证范围

窗口测试覆盖启动时保持原尺寸和位置、不同内容区尺寸的坐标换算、窗口移动与缩放后的坐标、前台与最小化检查、无效尺寸、移出主屏幕和窗口选择。状态机测试覆盖初始界面拒绝、选关启动、领取循环、体力/消耗零值、直接重试、三次失败、领取后重置失败计数、未知界面暂停及 F8。光标测试覆盖不同尺寸 / 背景、普通 Windows 光标与非光标图形的拒绝、实际位置范围、未识别时暂停及识别后再滚动选关。三星锚点测试覆盖真实三星图片、两颗星的拒绝、列表范围、缩放与移动、动态滚动位置、未识别时暂停及目标可见时立即点击。画面光标测试覆盖系统坐标固定时成功移动、系统移动但游戏光标不动时暂停、光标丢失、多个候选、真实家具边缘误识别拒绝和移动期间 F8。状态栏测试还覆盖截图排除的回退、截图失败后的恢复、窗口移动定位和未知 / 零营业额的显示。截图识别已用玩家提供的图一、三、四、五、六、七核对。

这些验证不能替代真实游戏运行。截图来自玩家设备，其他语言、不同 UI 缩放、弹窗遮挡或游戏不接收模拟输入可能导致识别或点击失败。首次运行请观察完整流程，必要时按 F8。
