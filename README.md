# 异环助手 · 店长特供

Windows 10/11 x64 桌面应用。安装后双击桌面“异环助手”快捷方式即可打开中文 GUI，不需要安装 Python 或另行下载 OCR 模型。

流程：锤子区域连点 → OCR 连续确认当前分数达到 1900 → Esc → 退出 → 确认领取 → 选择关卡并开始。识别到配置的都市体力不足提示后停止。

## 获取安装包

打开本仓库 **Actions → Windows installer → 最新成功的构建 → Artifacts → NTE-AI-Windows-installer**，下载并解压 ZIP，运行其中的 `NTE-AI-Setup-1.0.0.exe`。下载 Actions 附件需要登录 GitHub。构建尚未完成或失败时不会有可用安装包，请查看该次构建状态。

安装向导使用英语，应用界面使用中文。安装到当前用户目录，自动创建桌面和开始菜单快捷方式，支持从 Windows 设置卸载。安装版没有代码签名，Windows 可能显示未知发布者提示。

## 可视化操作

1. 将游戏放在主屏幕，固定窗口位置、分辨率和 UI 缩放。打开桌面“异环助手”。
2. 点击 **① 配置截图区域与操作步骤**：框选锤子点击区域、右上角完整的 `当前分数/1900`、真实“都市体力不足”提示中的稳定文字或图标。分数区域使用 OCR，不要只截取右侧 1900。
3. 在退出步骤开头加入 **Esc**，再依次录入“退出”“确认领取”按钮。每次添加点击步骤后，将鼠标放在对应游戏按钮上，3 秒后记录坐标；工具不会替你完成这次点击。自行切换页面后再录入下一步。
4. 按实际流程录入重进步骤，如选择关卡、开始。页面加载慢时增大每步等待时间。配置窗口会显示已录入步骤，支持清空后重录。
5. 保存配置并关闭配置窗口返回主页。配置可分次保存，尚未遇到体力不足提示时可保留现有配置以后补录；缺少必需项目时不能开始运行。
6. 点击 **② 检查当前画面**，窗口最小化后在 5 秒内切回游戏。检查不会点击，完成后 GUI 会恢复并显示识别分数、达成状态、体力不足状态。分别在正常和不足画面确认结果正确。
7. 在主页调整点击间隔、最多轮数、最多分钟和单轮超时，进入店长特供的新一轮点击阶段，点击 **③ 保存设置并开始**。窗口最小化后在 5 秒内切回游戏。首次建议最多 **2 轮**，观察完整流程。

**紧急停止：按 F8，或把鼠标移到主屏幕角落。** 主页也提供停止按钮，但运行时请优先使用 F8，避免切到 GUI 后游戏坐标点击到其他窗口。Esc 是游戏退出步骤，不用作停止键。

主页展示分数截图、体力不足模板和运行日志。运行时始终保持游戏在前台，不移动窗口、不操作其他程序。读不到分数时暂停点击，超时停止；不能因此判断体力已清空。只有配置的不足提示得到连续确认才会报告体力不足。

安装版配置和截图保存在 `%LOCALAPPDATA%\NTE-AI`，升级与卸载不删除这些个人配置。源代码运行时保存在源码目录。提示样式、屏幕或游戏缩放改变后请重新配置。

## 开发运行

需要 Windows 和 Python 3.12：

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe app.py
```

原命令行入口也保留：`python automation.py configure`、`check`、`run`。

## 构建 Windows 安装包

GitHub Actions 在 Windows 上自动构建，也支持 Actions 中手动 Run workflow。本地 Windows 构建需安装 Python 3.12 和 Inno Setup 6：

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt -r requirements-build.txt
python -m unittest discover -s tests -v
.\packaging\build.ps1
```

构建使用 PyInstaller 打包 Python、Tk GUI、OCR 模型及依赖，再使用 Inno Setup 生成 `dist/installer/NTE-AI-Setup-1.0.0.exe`。脚本检查打包后的 OCR/GUI，静默安装到临时目录，确认桌面快捷方式存在，再检查安装后的程序。静默安装检查会在构建机器创建测试快捷方式。

## 验证与限制

现有测试覆盖循环控制、分数解析、体力不足停止、超时、Esc 操作、F8 停止事件、运行上限及配置保存。Windows 构建额外验证真实依赖、打包后的 GUI/OCR、安装和快捷方式。

自动化测试不代表已在真实《异环》中验证。固定坐标和等待时间需要玩家校准；错误弹窗、加载速度变化或游戏不接收模拟输入时可能无法完成流程。当前实现不读取游戏内存，也不提供绕过游戏输入限制的方法。
