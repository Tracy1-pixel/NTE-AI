# 异环助手 · 店长特供 1.1.19

Windows 10/11 x64 桌面应用，安装后通过桌面“异环助手”打开中文 GUI。使用 EXE 安装包时无需单独安装 Python；也支持下载源码并通过 PowerShell 运行。新版内置玩家提供的七图界面模板和操作位置。

**1.1.19 更新：** 初始界面只识别左上“即刻落槌”；仪器列表、中央均价、出价键盘与结算按阶段进行局部 OCR，并跳过不需要的文字方向分类，减少整屏重复识别。未知阶段画面最多每两秒补一次整屏识别以恢复。均价门槛改为 **500,000**。

“即刻落槌”已接入完整循环：使用 **九格均价仪器**，均价 **严格大于 500,000** 时出价 **5,000,000** 并等待结算，随后跳过动画、退出；等于或低于门槛时点击左上退出并确认放弃。两条路径均等待加载、连续确认回到初始界面后重新开局，F8 / 停止按钮可结束。

## 安装与开始

### 方法一：EXE 安装包

[直接下载 Windows EXE 安装包](https://github.com/Tracy1-pixel/NTE-AI/releases/download/v1.1.19/NTE-AI-Setup-1.1.19.exe)，或打开 [Releases 下载页面](https://github.com/Tracy1-pixel/NTE-AI/releases/latest)，在 Assets 中选择 `NTE-AI-Setup-1.1.19.exe`。双击安装后，通过桌面 **“异环助手”快捷方式** 打开中文界面，点击“开始运行”或“停止”。无需下载源代码、解压 ZIP 或安装 Python。已有旧版可直接安装升级，应用配置目录为 `%LOCALAPPDATA%\NTE-AI`。

**启动时管理员授权：**安装程序仍安装到用户目录；实际助手 EXE 带有 `requireAdministrator` 权限声明。双击桌面快捷方式或 EXE 时，在 Windows 用户账户控制提示中选择 **“是”**（需要时输入管理员凭据），才会打开助手。取消授权时不会启动。无需每次右键设置；若已从管理员进程启动，Windows 可能不再显示提示。打开后窗口标题应为 **1.1.19**，运行记录中的“助手管理员”应为 **是**。

### 方法二：EXE 下载不了或无法使用时，下载源码并用 PowerShell 运行

1. 从 [Python 官网](https://www.python.org/downloads/windows/) 安装 **Python 3.12（64 位）**，安装时保留 Python Launcher（`py` 启动器）选项。
2. [下载源码 ZIP](https://github.com/Tracy1-pixel/NTE-AI/archive/refs/heads/main.zip)，或在仓库点击 **Code → Download ZIP**。将 ZIP 完整解压，进入能看到 `app.py`、`requirements.txt` 和 `assets` 的文件夹。如果已经下载了这样的源码文件夹，可以直接使用。
3. 在该文件夹空白处右键选择 **“在终端中打开”**，确认使用 PowerShell。Windows 10 可按住 **Shift** 再右键，选择 **“在此处打开 PowerShell 窗口”**。
4. 先检查 Python 版本：

```powershell
py -3.12 --version
```

显示 `Python 3.12.x` 后，在同一窗口依次执行：

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe app.py
```

首次安装依赖需要联网；看到依赖安装完成后，再执行最后一行打开中文界面。此方式直接使用虚拟环境中的 Python，无需执行 `Activate.ps1`，也无需修改 PowerShell 执行策略。

源码启动 `app.py` 或 `automation.py run/configure` 时，未取得管理员权限则先显示 Windows 授权提示，选择“是”后使用原 Python 环境、参数和工作目录重新启动；原进程退出。取消授权、权限检测失败或提权失败时会提示并退出，不开始脚本，不反复请求。`automation.py check` 只读检查仍可直接运行。

如果提示找不到 `py` 或没有 Python 3.12，请回到第 1 步安装相应版本和 Launcher，重新打开 PowerShell 后再试。如果提示找不到 `requirements.txt` 或 `app.py`，请回到第 2 步中的源码文件夹再打开终端。

以后启动时，在同一源码文件夹打开 PowerShell，只需执行：

```powershell
.\.venv\Scripts\python.exe app.py
```

**可选：为源码版创建桌面快捷方式。** 首次成功运行并关闭助手后，在同一源码文件夹的 PowerShell 中执行下面整段代码：

```powershell
$nteSourceRoot = (Get-Location).Path
$nteShortcutShell = New-Object -ComObject WScript.Shell
$nteDesktopPath = [Environment]::GetFolderPath('Desktop')
$nteSourceShortcut = $nteShortcutShell.CreateShortcut((Join-Path $nteDesktopPath '异环助手（源码）.lnk'))
$nteSourceShortcut.TargetPath = Join-Path $nteSourceRoot '.venv\Scripts\pythonw.exe'
$nteSourceShortcut.Arguments = '"' + (Join-Path $nteSourceRoot 'app.py') + '"'
$nteSourceShortcut.WorkingDirectory = $nteSourceRoot
$nteSourceShortcut.Save()
```

之后双击桌面 **“异环助手（源码）”** 即可打开界面。这个快捷方式依赖当前源码目录，请保留该目录及其中的 `.venv` 文件夹。

### 游戏准备与开始运行

助手**沿用游戏当前的窗口尺寸和位置**，不会调整游戏窗口或修改游戏设置。读取实际内容区后，自动换算识别区域和点击坐标。助手使用独立的深色控制台界面，显示窗口尺寸、运行阶段、营业额和完成 / 失败次数。

游戏窗口须在主屏幕完整可见。窗口位置可以改变，识别截图与点击坐标始终跟随游戏内容区，不包括桌面、标题栏和边框。不再要求固定 1920×1080，也不会为了适配桌面移动或缩放游戏窗口。

1. 打开店长特供的**图一初始界面**。
2. 打开助手，点击“刷新”，在“绑定游戏窗口”下拉框选中《异环》。标题能唯一识别时会自动选中。游戏打开后再刷新；多个同名窗口须手动选择。
3. 选择“运行模式”：**钢琴家循环**重复游玩 3-10；**闯关模式**启用“请选择开始关卡”下拉框，可选 1-1～1-10、2-1～2-10、3-1～3-10。选择哪关就从哪关开始，成功领取并返回后按编号进入下一关，直到完成 3-10。截图中的 1-0 教学关不在闯关列表内。
4. 设置点击、识别和滚动间隔，点击“开始运行”，助手会自动最小化，5 秒内切回初始选关界面。助手确认初始界面和游戏光标后，识别左侧连续三颗星的整体锚点，将光标移到锚点中心，每批滚动后 OCR 查找当前目标编号。编号已可见时直接点击；目标在上方则向上滚动，在下方则向下滚动。确认右侧标题选中了正确编号后点击右下角“开始营业”，进入倒计时和锤子连点。窗口变化时按实际内容区重新换算坐标。
5. “检查画面”只读，不会改变尺寸或点击，直接检查当前窗口。初始界面应显示 `home`，都市体力数值应与游戏一致。
6. **点击“停止”或按 F8 手动停止。** 助手运行时会最小化，可通过任务栏恢复界面点击停止；切到助手会暂停游戏操作。任务终止后，助手会自动恢复 GUI，显示结束原因和运行记录。运行中关闭 GUI 会提示先停止。鼠标移到角落、Esc、轮数和总时长不再是停止条件。

游戏切到后台、最小化或移出主屏幕时暂停操作；将窗口完整移回主屏幕并切回游戏后继续。F8 可停止当前运行。

**F8 停止：**开始运行、检查画面和鼠标诊断都会先启动 Windows 全局 F8 热键，并在独立线程中每 20 毫秒检查按键状态。全局注册被其他程序占用时，仍使用按键检测并在日志说明；监听不可用时拒绝开始。收到 F8 后先设置停止信号，停止发送后续鼠标输入，恢复助手界面显示“正在停止”，当前截图 / OCR 返回后结束本次工作并显示“已停止”；鼠标按下期间也会释放按键。每次任务结束会释放热键，可重复开始。F8 结束当前自动任务，助手窗口保留以便查看日志或再次启动；关闭软件请在停止后点击右上角 ×。普通键盘直接按 F8；多媒体键盘必要时使用 Fn+F8，确保实际发送 F8。

GUI 只展示窗口绑定、运行参数、操作按钮、实时状态和运行记录。识别参考图片及七图流程说明仅用于内部实现，不显示在界面中。无需手动录入不足提示、Esc 或进出步骤。1.0 的轮数、总分钟数和旧坐标配置在新版流程中不生效。

### 滚轮与 OCR 速度

“滚动间隔”默认 **0.1 秒**，最小 **0.05 秒**。每批发送 3 格滚轮，根据当前可见编号选择向上或向下，然后等待列表更新，再识别目标编号；不增加每批跨度，避免跳过目标。删除滚动后重复的按钮切换等待和识别间隔等待。间隔表示画面更新等待时间，实际滚轮频率还受截图、光标核验和 OCR 耗时影响。列表动画未稳定或识别困难时可调到 `0.2`～`0.3` 秒。

营业额、都市体力和领取消耗使用固定单行区域直接识别，省去重复的文字检测和方向分类；低置信度或格式错误时回退完整 OCR。选关滚动期间不重复识别右侧标题；点击目标编号后重新识别标题确认选中；闯关营业画面的编号也从每张新截图读取，优先使用单行直接识别。左侧编号仍使用完整 OCR 获取点击位置。所有数值每次从新截图读取，仍需原有的连续确认，不缓存体力或消耗，不把读不到当作零。

云端 CPU 对玩家数字截图的预热测试：旧数字 OCR 约 **164～534 毫秒/次**，新直接识别约 **13～27 毫秒/次**。这仅是数字区域 OCR 耗时，不是整轮耗时或玩家电脑上的速度保证。也验证了原图与缩小后还原的数字样例。

## 即刻落槌

点击左侧“店长特供”下方的 **即刻落槌**，界面切换到该功能；店长特供的模式 / 开始关卡选项隐藏，显示九格平均价值与运行阶段。尚未识别均价时显示“—”，零值显示“0”。运行中不能切换栏目。绑定游戏窗口后，从玩家提供的即刻落槌初始界面点击“开始运行”，助手最小化，5 秒内切回游戏。

1. 只读取左上“即刻落槌”确认初始界面。确认游戏光标后，实时定位仪器组方框，再复核位置后点击。
2. 识别“仪器组合”和“内含下列仪器”定位弹窗，将光标放在**左侧仪器组列表**内，向下滚动寻找“至尊仪器组”，不会滚动右侧仪器说明。目标已可见时直接点击。
3. 连续确认至尊仪器组的粉色选中边框，然后识别底部 **购买并使用 / 使用 / 一键补齐 / 一键补全** 中当前出现的按钮并点击。移动后重新识别界面、按钮及光标位置，确认后才输入。
4. 连续确认返回初始界面，再点击右下 **开始匹配 / 开始拍卖**。
5. 连续确认“匹配成功后将扣除入场费……是否继续”的专用提示，点击右侧“确认”。只处理此提示，不把其他界面的确认按钮视为入场确认。
6. 入场确认发送后等待匹配，识别右下角百分比及其左侧深色背景上的灰色图形，显示 **加载中**。只观察状态，不移动、点击或滚动；显示 100% 仍继续等待，F8 / 停止按钮保持有效。
7. 连续识别中央“竞拍第 N 回合”、左下“仪器”和右下“出价”后，点击左下“仪器”。未知画面不代表进入竞拍，不发送输入。
8. 在“仪器列表”中寻找并点击 **九格均价仪器**，目标不在可见范围时仅滚动该列表；确认目标可用边框和底部“使用”后点击使用。多个仪器都可能有粉色边框，因此边框仅表示可用，脚本仍先明确点击九格均价仪器。
9. 等待返回竞拍画面，读取中央 **九格均价仪器** 下方“本局内九格藏品的平均价值为……”的整数，连续确认相同值后记录。支持千位逗号和同一行拆分的 OCR 结果；资产、当前估价、推荐出价和格式异常的数字不作为均价。
10. 均价 **> 500,000** 时点击右下“出价”打开键盘，先“清空”，再按 **5 → 00 → 0000** 输入五百万，逐步检查输入反馈。连续核对输入金额为 **5,000,000** 后点击“确认出价”；出现异常高价二次提示时，仅在提示金额也是五百万时点击右侧“确认”。未出现二次提示而返回竞拍画面时也进入等待，不再次提交。
11. 提交后显示 **等待竞拍结果**，不重复使用仪器或追加出价。连续识别“竞拍结束”、成交价 / 实际价值 / 收益标签以及右下退出按钮后，点击“跳过动画”，再确认结算页面并点击“退出（Ns）”。动画按钮已消失时直接处理结算退出，不寻找替代按钮。
12. 均价 **≤ 500,000** 时点击由左上 ESC 标签定位的退出图标；连续识别 **确认退出** 及“放弃竞拍、不返还本局入场费”的专用提示后，点击右侧“确认”。此路径会放弃当前竞拍，入场费不返还。
13. 两条路径都只观察返回途中加载，不进行鼠标操作；连续确认回到即刻落槌初始界面后，完成局数加一（含低均价退出），清空本局均价及识别计数，重新确认光标、选择并使用至尊仪器组、开始下一局。未知页面不会触发新一局。
14. 自动循环持续至用户按 **F8 / 停止按钮**。结算、退出确认、加载和下一局准备期间都可取消，停止后不再发送后续输入。未定义的失败或余额不足页面会暂停等待，不自动选择其他仪器或出价金额。

使用按钮点击后若未返回首页，等待界面恢复，不重复购买；未选中、按钮有歧义、画面未知、光标离开目标或游戏不在前台时暂停。两批滚动后列表不变时停止滚轮并继续等待识别，F8 / 停止按钮可结束。该功能按用户指示会点击购买 / 补齐与入场费确认按钮，实际消耗取决于当前游戏显示。

识别锚点采用玩家图片中的文字、所在区域与边框颜色，数字始终读取实时截图；加载图形采用视觉结构判定，尚未制成精确动物模板。测试覆盖状态机、OCR 区域判定、阈值边界、金额核对、加载阶段无输入和 GUI 切换；Windows 安装后还使用生成的中文竞拍画面验证均价 OCR。玩家新截图尚未在真实游戏中完整验证，首次运行需要观察识别与输入结果。

## 游戏左下角状态栏

运行时，在游戏内容区左下角显示半透明状态栏，持续更新**实际窗口尺寸、模式、当前关卡、运行阶段、营业额、完成轮数 / 关数和连续失败次数**。内容区不可见或出现未知画面时显示暂停原因；恢复正确界面后继续。切换到其他窗口、最小化游戏或结束运行时隐藏状态栏。

状态栏采用普通 Windows 浮窗，鼠标点击穿透且不抢游戏焦点。截图识别时排除状态栏；旧版 Windows 或排除失败时，在截图期间临时隐藏，以免遮挡左侧选关的 OCR。状态栏随游戏窗口位置和尺寸变化，显示当前实际尺寸。

## 光标确认与三星整体锚点选关

点击开始后，助手自动最小化，确认图一，然后**先识别玩家照片中的游戏箭头光标，识别成功后才移动和滚动**。光标是图形，使用 OpenCV 轮廓识别；关卡编号文字（如 `1-1`、`3-10`）使用 OCR，无需全部关卡名字的图片。

默认识别依据照片中箭头的尖头、宽肩和内凹轮廓，支持不同大小。当前版本在游戏截图中定位箭头，不要求它靠近 Windows 系统坐标；还检查箭头方向和完整形状，避免把文字或家具边缘当成光标。多个画面候选无法唯一定位时暂停；定位后在上次确认位置周围跟踪。截图不包含系统光标时，读取并绘制当前 Windows 光标进行图形识别；游戏自己绘制的光标直接在画面中识别。不会只因为鼠标坐标存在就视为识别成功。

未识别到目标光标时，状态栏显示“识别游戏光标”，暂停移动、滚动和点击，等待光标出现；请先将鼠标置于游戏内容区。识别成功后，在左侧关卡栏寻找**横向连续三颗金色五角星**：尺寸相近、间距均匀的三颗星组合成一个整体锚点，光标移动到这个整体的中心，再开始按可见编号选择方向滚动。每批滚动前重新定位三星组合，每批滚动后用 OCR 查找当前目标编号，找到即停止滚动并点击。编号已经出现在当前列表时，直接点击，无需额外滚动。确认选中后，再移动到右下角点击开始营业。

编号可作为独立 OCR 文字识别，无需同时读出关卡名称；编号要求完整匹配，`1-1` 不会匹配 `1-10`，`13-10`、`3-100` 等不同编号不会作为目标。三星组合只在左侧关卡栏识别。完整三星锚点未出现时暂停鼠标移动和滚动；连续两批列表不再变化且仍未读到当前目标时，暂停滚轮但继续 OCR 等待，不会随意点击其他关卡。后续领取循环会再次确认光标和三星锚点，失败直接重试仍按原流程进行。

这张照片并非原始游戏截图，默认轮廓识别尚未在玩家设备验证；如果持续无法识别，应提供清晰的游戏原始截图以进一步适配。F8 或停止按钮仍可结束等待，并恢复 GUI。

## 鼠标输入与操作核验

当前版本区分两种光标：

- **画面中的游戏光标**：从截图获取真实位置，发送小批相对输入，再截图核验并修正；即使 Windows 系统坐标被游戏固定，也以画面反馈判断是否到达。不会将发送的目标坐标当作实际位置，不修改游戏的鼠标限制。光标丢失、候选有歧义或输入后画面光标不动时暂停，不继续点击。
- **Windows 光标**：从系统读取位置，保留相对 `SendInput`、绝对 `SendInput` 和 `SetCursorPos` 定位；输入后核验系统坐标及目标位置处的光标。目标不在系统活动范围时暂停。

选关、开始营业、锤子连点、退出和领取都使用对应的光标反馈。真实游戏是否接收这些输入仍需实测，测试通过不能代替玩家设备的结果。

新增 **“鼠标诊断”** 按钮：选中游戏窗口后点击，助手最小化，5 秒内切回游戏；只读输出系统坐标、`GetClipCursor` 鼠标活动范围、助手和所选游戏进程实际管理员状态、游戏内容区及前台状态。诊断不移动、点击或滚动。每次开始运行也会自动输出权限和范围信息。系统光标的目标不在活动范围时暂停；画面光标使用画面位置反馈。不会解除游戏的鼠标限制。

如果手动能移动、脚本不能移动，请复制“鼠标诊断”及“鼠标移动未确认”完整记录。`SendInput` 返回已接收，只代表 Windows 接收了事件，不能证明游戏处理了事件；日志和测试不会将二者混同。

OCR 读到目标编号只证明找到了关卡文字。发送点击后，须识别右侧标题确认选中，才允许开始营业；开始点击后须识别倒计时 / 营业画面，才报告开始成功。滚轮输入后列表不变时，显示“列表未变化，无法确认是否到底或游戏未接收输入”，不会直接宣称已滚到底。

如果日志显示“助手管理员=否，游戏进程管理员=是”，两者权限不一致，可先关闭旧版助手，右键快捷方式选择“以管理员身份运行”；**1.1.11 起会主动请求管理员授权**。两者权限相同仍无法操作时，应查看上述坐标与游戏光标确认日志。Windows 构建会读取打包后及安装后 EXE 的管理员权限声明，启动自检确认实际进程为管理员，再向专用测试窗口发送移动、点击和滚轮并核验接收事件；也检查绝对坐标定位、SetCursorPos、活动范围和进程权限读取。这能验证启动权限及输入接口，真实游戏效果仍需玩家实测。

## 自动流程

### 闯关模式

选择开始关卡后，按 **1-1…1-10 → 2-1…2-10 → 3-1…3-10** 的数值顺序继续，不会按文字排序将 1-10 排在 1-2 前。每关流程为：确认初始界面 → 确认光标与三星锚点 → 滚动识别目标编号 → 点击并确认右侧选中 → 开始营业 → 连点锤子 → 连续确认营业额达到本关分母目标 → 退出 → 识别本次领取消耗 → 领取 → 连续确认回到选关界面 → 进入下一关。未确认返回前不推进编号，也不重复点击领取。

失败时重新挑战**当前关卡**，不跳到下一关；成功领取后连续失败计数归零。完成并领取 3-10 后停止；都市体力为 0、领取消耗为 0、连续失败三次也会停止。识别失败或界面切换未完成时暂停等待；手动停止使用 F8 或停止按钮。主界面和游戏左下角状态栏显示当前关卡、目标营业额与完成关数。

其他关卡按与钢琴家相同的锤子、退出、失败重试和结算界面实现。若某关布局不同，需要该关原始截图适配；不需要为每个关卡名字准备 OCR 锚点图片。

### 钢琴家循环

| 图片 | 识别与操作 |
| --- | --- |
| 图一 | 连续确认店长特供标题与开始营业按钮，才允许开始；先连续识别游戏光标，识别左侧连续三星整体锚点，光标移到锚点上逐批滚动 |
| 图二 | 每批滚动后 OCR 查找 `3-10 钢！琴！家！`，找到即停止滚动，移动光标点击关卡并确认右侧已选中，再将光标移到右下角点击开始营业 |
| 图三 | 倒计时期间即可开始连续点击左侧锤子 |
| 图四 | 保持锤子连点，定期读取右上角营业额 |
| 图六 | 连续确认营业额达到 1900 后停止连点，点击左上角退出图标 |
| 图七 | 连续确认成功结算，读取领取下方消耗，非零且可读时领取；回到图一继续 |
| 图五 | 连续确认失败，点击“重新挑战”；直接等待倒计时并连点，不返回图一选关 |

每次成功领取并返回图一，连续失败计数归零。连续失败三次终止当前运行。

领取下方的消耗**不是固定 48**。每次结算都会重新 OCR 读取当前数字，任何可读的非零消耗都允许领取并继续循环；例如 `48 → 24 → 7 → 0`，前三次领取，最后确认 0 时停止，且不点击领取。内部识别素材中的 48 只是截图样例。

都市体力完整分数中的左侧值连续确认为 0，或者领取按钮下方的消耗连续确认为 0，都自动停止。OCR 读不到为未知，**不会当作 0**。这些是自动结束条件；手动停止使用停止按钮或 F8。

初始画面不匹配时显示“界面错误”并拒绝开始。运行过程中出现未知画面或页面切换迟迟未完成时，暂停点击并在日志显示错误，继续等待正确界面或 F8；不会因普通加载超时直接退出。挑战自身倒计时结束出现图五时走失败重试流程。

钢琴家循环的营业额目标为 1900；闯关模式读取营业额分数的分母作为本关目标，分母不可读或变化时不会累计达标确认。星星是界面反馈，不代替营业额判断。工具使用截图、OCR 和普通鼠标输入，不读取游戏内存。
