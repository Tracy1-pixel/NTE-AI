本次版本 **1.1.18**，下一版为 **1.1.19**。即刻落槌增加结算、退出确认和自动循环。

下载 **NTE-AI-Setup-1.1.18.exe**，关闭旧版后安装，从桌面 **异环助手** 快捷方式打开，在管理员授权提示中选择“是”。

- 入场、至尊仪器组购买 / 使用、加载观察和九格均价读取保留；**均价 > 350,000** 时核对并出价 **5,000,000**，随后等待，不重复出价。
- 竞拍结束时识别成交价、实际价值、收益和退出按钮，点击 **跳过动画**，再点击 **退出（Ns）**。动画按钮已消失时直接退出结算。
- **均价 ≤ 350,000** 时点击左上退出；只在明确识别 **确认退出** 与“放弃竞拍、不返还本局入场费”的专用提示后点击右侧确认。
- 两条路径均等待加载和初始界面连续确认，再增加完成局数（包含主动退出局），清空本局均价与识别计数，重新选仪器并开局。未知返回画面不计局、不重复购买或开始。
- 自动循环直到 **F8 / 停止按钮**；结算、确认退出和加载中均可取消。未知错误、余额不足或未定义的页面暂停，不自动改用其他仪器或金额。
- 原店长特供功能、管理员启动、读取当前游戏窗口尺寸和状态栏保留。

测试覆盖低均价退出和成功拍下各连续三局、跳过动画先于退出、专用退出提示限定、未确认首页不得重启、循环均价清空，以及结算 / 退出期间取消。均价、金额核对、阈值边界和键盘输入测试保留；Windows 安装验证中文均价和键盘的实际 OCR、GUI、鼠标、F8、权限及桌面快捷方式。

识别锚点使用玩家图片中的文字、位置和边框，数字读取实时画面。完整真实游戏效果仍需在玩家设备上实测。EXE 无法下载或使用时，可使用 README 的源码 + PowerShell 方法。
