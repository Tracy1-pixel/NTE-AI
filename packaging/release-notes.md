本次版本 **1.1.16**，下一版为 **1.1.17**。新增“即刻落槌”栏目与入场准备流程。

下载 **NTE-AI-Setup-1.1.16.exe**，关闭旧版后安装，从桌面 **异环助手** 快捷方式打开，在管理员授权提示中选择“是”。

- 左侧“店长特供”下方新增 **即刻落槌**，独立显示目标仪器组、准备阶段和运行记录；运行中禁止切换功能。
- 从即刻落槌初始界面开始，确认游戏光标后点击仪器组方框；识别弹窗左右列，将滚轮放在左侧仪器组列表，向下寻找 **至尊仪器组** 并点击。
- 连续确认粉色选中边框，再点击底部当前出现的 **购买并使用 / 使用 / 一键补齐 / 一键补全**。移动后重新识别界面、按钮和实际光标位置，未确认时不输入。
- 确认返回初始界面后点击右下 **开始匹配 / 开始拍卖**。识别“匹配成功后将扣除入场费……是否继续”的专用提示，再点击右侧 **确认**。
- 入场确认发送后等待匹配，识别右下百分比及灰色图形显示 **加载中**，不移动、点击或滚动；100% 时也继续等待。加载标识连续消失后结束本次准备，GUI 显示 **等待后续流程**。游戏内竞价与后续结算等待用户补充。
- 未选中、未返回首页、按钮不明确或界面未知时等待，不重复购买。列表两批未变化时暂停滚轮。F8 / 停止按钮、管理员启动、当前窗口尺寸读取及状态栏继续使用。
- 店长特供的钢琴家循环和闯关模式保留，1.1.15 的负数等待修复保留。

新增测试覆盖三类使用按钮及补全别名、左列定位、选中边框、返回首页后再开始、入场提示限定、重复购买防止、中途取消、加载百分比区域与图形、100% 继续等待和加载期间无输入。Windows 构建验证安装后两栏切换、原闯关控件恢复、OCR、权限、状态栏、实际鼠标输入和 F8。

该功能按用户指示会确认当前游戏的购买 / 补齐和入场费。玩家新界面的完整真实游戏效果仍需实测。EXE 无法下载或使用时，可使用 README 的源码 + PowerShell 方法。
