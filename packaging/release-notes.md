本次版本 **1.1.10**；后续每次修改递增末位编号，下一版为 **1.1.11**。

下载下面的 **NTE-AI-Setup-*.exe** 安装包，双击安装。安装完成后，从桌面 **异环助手** 快捷方式打开中文控制台，无需安装 Python 或下载源代码。

- 精简控制台：移除下方三星锚点、营业额、领取消耗的参考图片，以及“七图流程说明”入口和侧栏静态流程介绍。运行记录使用释放的空间，识别素材和自动流程保留在内部代码中。

- 提高选关滚轮频率：移除重复等待，GUI 新增“滚动间隔”，默认 0.1 秒，最小 0.05 秒。每批仍滚 3 格并 OCR 检查目标；实际频率取决于截图、光标核验和识别耗时。
- 数字 OCR 直接识别固定单行区域，低置信度或格式无效时回退完整 OCR；每次使用新截图，保留连续确认。云端数字截图预热测试由约 164～534 毫秒降至 13～27 毫秒，实际玩家设备速度需实测。
- 滚动时不重复识别右侧标题，点击 `3-10` 后仍须确认选中。OCR 未读到数字不会作为零。
- 游戏画面光标使用截图位置反馈，系统坐标固定时也可按画面位置核验相对移动；方向与完整形状匹配排除家具或文字误识别。光标未到位不点击，真实游戏效果需玩家设备验证。

- 增加鼠标兼容回退：相对移动失败时尝试绝对 SendInput 和 SetCursorPos，读取即时及延后实际坐标；所有方式均失败时暂停，不继续点击。
- 新增只读“鼠标诊断”：输出活动范围、助手 / 游戏进程实际管理员状态与窗口信息；不解除游戏鼠标限制。
- 点击操作记录为“已发送输入”，以右侧选中标题、倒计时 / 营业画面确认成功；列表不变不会宣称滚动到底。
- 主界面支持开始运行、停止和 F8 快捷停止。
- 游戏左下角显示窗口尺寸、运行阶段、营业额和完成 / 失败次数。
- 启动后确认图一和目标游戏光标，将左侧连续三颗星作为一个整体锚点，光标移到锚点上逐批滚动；每批 OCR 查找 3-10，找到后点击，再移动到右下角开始营业。光标或完整三星锚点未识别时暂停等待。
- 每次结算重新识别领取消耗；非零时领取，确认零值时停止。
- 沿用当前游戏窗口尺寸和位置，不再强制调整为 1920×1080；识别和点击按实际内容区自动换算，窗口须在主屏幕完整可见。

适用于 Windows 10/11 x64。此安装包已通过自动安装、桌面快捷方式、界面启动、停止按钮、真实三星锚点与 3-10 OCR、Windows 光标图形读取、当前内容区只读获取与坐标换算、状态栏以及专用测试窗口实际鼠标移动 / 点击 / 滚轮事件检查。这些检查不代表真实游戏一定接受模拟输入。默认光标识别依据照片中的箭头轮廓，真实游戏运行仍需首次使用时观察。
