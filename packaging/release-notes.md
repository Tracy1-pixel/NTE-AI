本次版本 **1.1.15**，下一版为 **1.1.16**。

下载 **NTE-AI-Setup-1.1.15.exe**，关闭旧版后安装，从桌面 **异环助手** 快捷方式打开，在 Windows 管理员授权提示中选择“是”。窗口标题应显示 1.1.15。

- 修复 **sleep length must be non-negative** 报错：旧等待代码在“判断是否到期”和“计算剩余时间”时分别读取时间，线程调度或检查耗时可能让第二次读取越过期限，产生负数。
- 新等待循环先检查停止信号，再读取一次剩余时间；到期直接结束等待，只向 sleep 传入正数。当前流程和旧等待实现均已修复。
- 保留不超过 50 毫秒的分段等待及 F8 / 停止按钮响应；零等待也检查取消信号。
- 闯关仍从用户选择的关卡持续至 3-10，成功领取并确认返回后进入下一关。钢琴家循环、动态营业额目标、变量领取消耗、零体力 / 零消耗 / 三次失败停止、窗口尺寸读取及状态栏均保留。
- 保留 Windows 全局 F8 热键与独立按键检测。F8 结束当前自动任务并恢复 GUI；要关闭整个助手，在停止后点击右上角 ×。

新增测试复现计时跨越期限的条件，并验证正常等待、等待中取消和零等待取消；完整自动流程与 Windows 安装后的 GUI、权限、OCR、实际鼠标及 F8 检查仍运行。

适用于 Windows 10/11 x64。EXE 无法下载或使用时，可按 README 的源码 + PowerShell 方法启动。
