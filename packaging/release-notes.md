本次版本 **1.1.17**，下一版为 **1.1.18**。即刻落槌新增九格均价读取与条件出价。

下载 **NTE-AI-Setup-1.1.17.exe**，关闭旧版后安装，从桌面 **异环助手** 快捷方式打开，在管理员授权提示中选择“是”。

- 入场、至尊仪器组购买 / 使用及加载观察保留；加载标识消失后继续确认实际竞拍界面，未知画面不触发输入。
- 识别左下“仪器”并打开列表，定位“九格均价仪器”，点击后使用；中央均价说明连续读到相同整数后，GUI 与游戏状态栏显示实际数值。
- **均价 > 350,000**：点击右下出价，通过游戏数字键盘清空旧金额，按 5 → 00 → 0000 输入 **5,000,000**，逐键验证反馈并核对最终金额后提交。
- 异常高价二次提示只在明确识别到 **5,000,000** 时点击“确认”；示例中的其他金额不会被当作目标金额。提交后仅等待竞拍结果，不追加或重复出价。
- **均价 ≤ 350,000**：点击左上退出图标；确认返回初始界面后结束。未知退出确认、结算和自动循环尚未实现，遇到这些画面等待后续流程。
- 数值未识别、格式异常、输入金额或确认金额不一致时暂停操作；F8 / 停止按钮保持可用。原店长特供模式、管理员启动、游戏窗口尺寸读取继续保留。

验证覆盖均价与资产 / 估价区分、千位分隔符、同一行 OCR 拼接、仪器列表定位、严格阈值边界、五百万逐键输入、错误金额不提交、二次确认不匹配时暂停、一次出价后等待以及取消操作。Windows 构建和安装检查均价 GUI 显示、生成的中文竞拍画面的实际 OCR、鼠标、F8、权限和桌面快捷方式。

竞拍界面的真实游戏效果仍需在玩家设备上实测；OCR 锚点取自提供的文字和布局，没有把示例均价固定进脚本。EXE 无法下载或使用时，可使用 README 的源码 + PowerShell 方法。
