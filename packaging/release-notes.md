下载下面的 **NTE-AI-Setup-*.exe** 安装包，双击安装。安装完成后，从桌面 **异环助手** 快捷方式打开中文控制台，无需安装 Python 或下载源代码。

- 主界面支持开始运行、停止和 F8 快捷停止。
- 游戏左下角显示窗口尺寸、运行阶段、营业额和完成 / 失败次数。
- 启动后先确认图一和目标游戏光标，再移动到左侧滚动到底，OCR 识别并选择 3-10，最后移动到右下角开始营业；没识别到光标时暂停等待。
- 每次结算重新识别领取消耗；非零时领取，确认零值时停止。
- 游戏使用普通窗口模式，内容区为 1920×1080，桌面需容纳窗口及边框。

适用于 Windows 10/11 x64。此安装包已通过自动安装、桌面快捷方式、界面启动、停止按钮、Windows 光标图形读取、状态栏和 OCR 检查。默认光标识别依据照片中的箭头轮廓，真实游戏运行仍需首次使用时观察。
