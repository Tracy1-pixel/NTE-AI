本次版本 **1.1.13**，下一版为 **1.1.14**。新增闯关模式，原钢琴家循环保留。

下载下面的 **NTE-AI-Setup-1.1.13.exe**，双击安装后从桌面 **异环助手** 快捷方式打开。在 Windows 管理员授权提示中选择“是”；无需安装 Python。

- 在“运行模式”选择 **闯关模式**，然后通过“请选择开始关卡”下拉框选择起点：1-1～1-10、2-1～2-10、3-1～3-10，共 30 关，不包含 1-0 教学关。
- 确认初始选关界面和游戏光标，移到左侧连续三星整体锚点，根据可见编号向上或向下滚动。OCR 精确识别当前目标，点击后须确认右侧选中，才开始营业。
- 连点锤子，营业额目标按本关画面分母读取。达标后退出、识别当前领取消耗并领取；确认返回选关界面后再进入下一关。未确认返回时不推进，不重复领取。
- 失败重新挑战当前关卡，不跳关；成功领取后重置连续失败计数。完成并领取 3-10、都市体力或领取消耗确认为 0、连续失败三次时停止。F8 / 停止按钮随时手动结束并恢复 GUI。
- 主界面与游戏左下角状态栏显示模式、当前关卡、营业额目标、完成关数及失败次数。关卡编号与数值均从新截图读取，读不到不会当作零。
- 钢琴家循环仍重复 3-10，保留管理员启动、点击到位核验、滚动间隔、数字 OCR 提速和未知画面暂停；沿用游戏当前尺寸与位置。

安装包构建会验证管理员声明、自动安装、桌面快捷方式、GUI 模式切换与 30 关列表、真实截图 1-1 / 3-10 OCR、停止按钮、状态栏，以及专用测试窗口的实际鼠标移动、点击和滚轮接收。闯关状态机验证完整 30 关顺序、跨章、领取后推进、失败重试和动态目标。

适用于 Windows 10/11 x64。其他关卡按同样的锤子和结算布局实现；真实游戏完整闯关仍需玩家实测，若某关布局不同，需要原始截图进一步适配。EXE 无法下载或使用时，可按仓库 README 的第二种方法下载源码，通过 PowerShell 启动。
