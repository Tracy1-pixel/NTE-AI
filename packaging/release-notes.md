本次版本 **1.1.19**，下一版为 **1.1.20**。即刻落槌 OCR 提速，均价门槛改为五十万。

下载 **NTE-AI-Setup-1.1.19.exe**，关闭旧版后安装，从桌面 **异环助手** 快捷方式打开，在管理员授权提示中选择“是”。

- 初始界面仅识别左上角“即刻落槌”，不再等待仪器组与开始按钮同时识别；点击前实时定位并复核操作按钮。
- 根据运行阶段裁剪仪器弹窗、中央均价、键盘与结算区域，将多个区域拼为一次 OCR，并跳过文字方向分类。坐标映射回原游戏内容区。
- 未识别到预期阶段时，每两秒最多一次整屏识别帮助恢复；成功恢复后该区域在本次运行改用实时整屏识别。不缓存或复用旧金额、旧按钮位置。
- **九格均价 > 500,000** 时出价 **5,000,000**；**≤ 500,000** 时退出并确认放弃。成功结算或主动退出返回首页后重新使用仪器、开局，持续到 F8 / 停止按钮。
- 连续均价核对、键盘逐步金额核对、异常高价确认、光标反馈、管理员启动与原店长特供功能保留。

Windows 构建验证安装后的 GUI、局部中文 OCR、鼠标、F8 和桌面快捷方式。真实游戏速度取决于玩家设备与画面，仍需实测。EXE 无法下载或使用时，可使用 README 的源码 + PowerShell 方法。
