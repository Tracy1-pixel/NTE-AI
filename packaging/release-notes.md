本次版本 **1.1.14**，下一版为 **1.1.15**。修复 F8 停止方式，保留从选择关卡连续闯关至 3-10 的模式。

下载 **NTE-AI-Setup-1.1.14.exe**，安装后从桌面 **异环助手** 快捷方式打开，在 Windows 管理员授权提示中选择“是”。请关闭旧版后再运行新版，标题应显示 1.1.14。

- F8 改用 **Windows 全局热键 + 独立按键检测**，不再只依赖键盘钩子。运行期间独立线程每 20 毫秒检查，游戏在前台、助手最小化或 OCR 正在运行时仍可发出停止信号。
- 收到 F8 后禁止后续鼠标操作，恢复 GUI 显示“正在停止”；当前截图 / OCR 完成后结束任务，显示“已停止”。鼠标已按下时仍会释放按键，结束后注销热键，允许再次运行。
- 热键被占用时启用独立按键检测并记录提示；监听不可用时不开始自动操作，运行中检测异常时停止任务。保留 GUI 停止按钮和助手前台 F8 绑定。
- F8 停止当前自动任务，保留助手界面；要退出整个软件，在停止后点击右上角 ×。多媒体键盘必要时使用 Fn+F8。
- 闯关从用户选择的关卡一直按数值顺序运行到 3-10。例如选择 2-4，则完成 2-4…2-10 → 3-1…3-10。每关成功领取并确认返回后才推进，用户取消后不再开始下一关。
- 原体力 / 领取消耗为零、连续失败三次的停止条件保留。原钢琴家循环、三星锚点双向滚动、动态营业额目标、管理员启动、当前窗口尺寸读取与游戏状态栏保留。

Windows 构建在专用测试窗口实际发送短按 F8，验证全局热键；单独禁用注册并按住 F8，验证独立按键检测；同时检查 GUI 恢复。测试还覆盖监听异常、热键占用、释放、重复运行，以及从中间关卡持续至 3-10 和用户中途取消。安装检查覆盖管理员权限、桌面快捷方式、GUI、OCR 与实际鼠标输入。

适用于 Windows 10/11 x64。真实游戏的按键和输入兼容性仍需玩家实测。EXE 无法下载或使用时，可按 README 的源码 + PowerShell 方法启动。
